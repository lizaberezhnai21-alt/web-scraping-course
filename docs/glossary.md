# Словник термінів

| Термін | Пояснення |
|---|---|
| Веб-скрейпінг | Автоматизоване отримання даних із вебсторінок |
| HTML | Мова розмітки, що визначає структуру вебдокумента |
| Тег | Елемент HTML-розмітки |
| Атрибут | Додаткова характеристика HTML-елемента |
| API | Програмний інтерфейс для взаємодії між системами |
| CSV | Текстовий формат табличних даних |
| JSON | Текстовий формат структурованого обміну даними |
| Очищення даних | Виявлення та виправлення проблем у наборі даних |
| Візуалізація | Подання даних у вигляді графіків і діаграм |
| BeautifulSoup | Python-бібліотека для аналізу HTML та XML |
| pandas | Python-бібліотека для обробки й аналізу табличних даних |
