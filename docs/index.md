## Як працювати з курсом

1. Послідовно опрацьовуйте навчальні модулі.
2. Виконуйте практичні завдання та завантажуйте надані файли.
3. Запускайте й змінюйте приклади Python у пісочниці або власному середовищі.
4. Перевіряйте розуміння тем за допомогою тестів.
5. Наприкінці курсу виконайте підсумковий проєкт.
