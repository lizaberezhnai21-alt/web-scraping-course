# Навчальні модулі

Курс складається з десяти модулів. Рекомендована тривалість — 35 годин.

| № | Назва | Орієнтовно |
|---:|---|---:|
| 1 | Вступ до веб-скрейпінгу | 2 год |
| 2 | HTML і структура вебсторінки | 4 год |
| 3 | Python для роботи з вебданими | 4 год |
| 4 | Отримання даних за допомогою BeautifulSoup | 6 год |
| 5 | Збереження та структурування даних | 3 год |
| 6 | Очищення та обробка даних | 5 год |
| 7 | Основи аналізу даних | 3 год |
| 8 | Візуалізація та інтерпретація | 3 год |
| 9 | Правові та етичні аспекти | 2 год |
| 10 | Підсумковий проєкт | 3 год |

Кожен модуль поступово доповнюватиметься теорією, прикладами, практичними роботами та тестами.
