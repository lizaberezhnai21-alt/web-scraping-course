# Модуль 1. Вступ до веб-скрейпінгу

**Тривалість:** 2 години

## Мета

Сформувати уявлення про веб-скрейпінг, його призначення, основні етапи роботи з даними та сфери практичного застосування.

## Очікувані результати

Після опрацювання модуля учень/учениця:

- пояснює поняття веб-скрейпінгу;
- розрізняє ручний збір даних, веб-скрейпінг та API;
- наводить приклади використання вебданих;
- описує шлях від вебсторінки до набору даних;
- називає базові правила відповідального збору інформації.

## 1. Що таке веб-скрейпінг?

**Веб-скрейпінг (web scraping)** — автоматизоване отримання певних даних із вебсторінок за допомогою програмних засобів.

Наприклад, дослідник може вручну переглянути десятки сторінок і записати назви книжок та їхні ціни. Програма для веб-скрейпінгу здатна автоматизувати отримання таких полів, якщо сайт дозволяє автоматизований доступ.

## 2. Основні етапи роботи

1. Визначення дослідницького запитання.
2. Вибір дозволеного джерела даних.
3. Отримання HTML або даних через API.
4. Вилучення потрібних полів.
5. Перевірка, очищення та структурування.
6. Аналіз і візуалізація.
7. Формулювання висновків.

## 3. Порівняння способів отримання даних

| Спосіб | Як працює | Коли доречний |
|---|---|---|
| Ручний збір | Людина переносить дані самостійно | Невеликий обсяг |
| Веб-скрейпінг | Програма аналізує доступну структуру сторінки | Коли потрібні дані опубліковані на сторінках і автоматизований доступ дозволено |
| API | Сервіс надає дані через визначений інтерфейс | Коли доступний відповідний API |

## 4. Приклад дослідницького завдання

**Запитання:** як відрізняються ціни на кілька категорій товарів у вибраному наборі даних?

Можливі поля таблиці:

| Назва | Категорія | Ціна, грн |
|---|---|---:|
| Навушники A | Аудіо | 1200 |
| Миша B | Периферія | 650 |
| Клавіатура C | Периферія | 1450 |

Це умовні навчальні дані, а не актуальні ціни магазинів.

## Практичні завдання

### Завдання 1. Визнач джерело та дані

Для кожного ресурсу запропонуй 2–3 типи інформації, які можуть бути корисними для дослідження: каталог книжок, сторінка прогнозу погоди, портал вакансій, сайт новин.

### Завдання 2. Обери спосіб отримання

1. Потрібно записати адресу одного закладу освіти.
2. Потрібно опрацювати каталог із сотнями записів, якщо автоматизований доступ дозволено.
3. Потрібно отримати погодні показники через офіційний API.

Для кожної ситуації обери ручний збір, веб-скрейпінг або API та поясни вибір.

### Завдання 3. Сплануй дослідження

Обери тему (книжки, погода, вакансії або товари) і запиши:
- дослідницьке запитання;
- можливе відкрите джерело;
- 3–5 потрібних полів;
- спосіб збереження;
- спосіб порівняння або аналізу.

## Підсумок

Веб-скрейпінг — лише один з етапів роботи з даними. Цінність дослідження визначається також якістю джерела, коректністю обробки та обґрунтованістю висновків.
