# Модуль 10. Підсумковий проєкт

**Тривалість:** 3 години

Учні виконують невелике дослідження на основі відкритого набору даних або дозволеного джерела. Проєкт має містити дослідницьке запитання, опис джерела, набір даних, етапи обробки, аналіз, візуалізацію та висновки.

Детальні вимоги наведено у [завданні підсумкового проєкту](../../projects/final-project.md).
