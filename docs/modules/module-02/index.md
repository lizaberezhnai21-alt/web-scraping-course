# Модуль 2. HTML і структура вебсторінки

**Тривалість:** 4 години

У цьому модулі учні ознайомляться з HTML-документом, тегами, атрибутами, вкладеністю елементів і структурою вебсторінки. Навчаться знаходити потрібні елементи за допомогою інструментів розробника браузера.

**Практичний результат:** визначити HTML-елементи, у яких містяться заголовок, посилання, зображення та текстовий блок.

*Матеріал буде доповнено прикладами HTML, вправами та тестом.*
