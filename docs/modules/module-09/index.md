# Модуль 9. Правові та етичні аспекти

**Тривалість:** 2 години

Відкритість інформації не означає необмежене право на її автоматизований збір і повторне використання. Учні аналізують умови використання ресурсів, правила доступу, авторське право, персональні дані, навантаження на сервери та коректне зазначення джерел.

**Практичний результат:** оцінити навчальний сценарій збору даних і визначити безпечний спосіб дій.
