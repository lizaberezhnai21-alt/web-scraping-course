# Модуль 3. Python для роботи з вебданими

**Тривалість:** 4 години

Повторення змінних, рядків, списків, словників, циклів, умов, функцій і роботи з файлами. Підготовка середовища Python та встановлення бібліотек.

**Практичний результат:** опрацювати список словників і зберегти результат у файл CSV.
