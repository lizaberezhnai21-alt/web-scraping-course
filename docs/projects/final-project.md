# Підсумковий проєкт

## Мета

Виконати невелике дослідження, у якому поєднано отримання, обробку, аналіз і візуалізацію даних.

## Етапи

1. Сформулювати дослідницьке запитання.
2. Обрати відкритий набір даних або вебресурс, умови якого дозволяють запланований спосіб отримання інформації.
3. Описати джерело та структуру даних.
4. Отримати або завантажити дані.
5. Очистити й підготувати набір.
6. Виконати щонайменше два види аналізу.
7. Створити одну або кілька доречних візуалізацій.
8. Сформулювати висновки та зазначити обмеження дослідження.

## Що подати

- файл даних CSV або JSON;
- програмний код або ноутбук;
- 1–2 графіки;
- короткий звіт (1–2 сторінки);
- посилання на джерело та опис способу отримання даних.

## Критерії оцінювання (20 балів)

| Критерій | Бали |
|---|---:|
| Дослідницьке запитання та вибір джерела | 3 |
| Коректність отримання даних | 3 |
| Очищення та підготовка | 4 |
| Аналіз | 4 |
| Візуалізація | 3 |
| Висновки, оформлення та посилання на джерела | 3 |
| **Разом** | **20** |
